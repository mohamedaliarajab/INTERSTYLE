FILENAMES DO NOT NEED TO BE EXACT. Save them under whatever names they
arrive with -- the gallery retries .jpeg / .png / .webp automatically, so
they will show either way, as long as each filename has the right number.

To compress them (recommended):

    python3 tools/optimise-images.py assets/img/products/tools-accessories
